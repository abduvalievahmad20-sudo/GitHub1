# Student Portfolio — Абдувалиев Ахмад

Адаптивный сайт-портфолио студента IT-направления. Проект сделан на HTML, CSS и JavaScript без сборщиков и дополнительных библиотек.

## Файлы проекта
- `index.html` — структура и содержание сайта.
- `style.css` — оформление, адаптивная сетка и мобильная версия.
- `script.js` — мобильное меню и автоматическое обновление года.
- `.gitignore` — исключения для Git.

## Как запустить
Откройте `index.html` в браузере. Для редактирования можно использовать Visual Studio Code.

## Публикация через GitHub Pages
1. Загрузите все файлы проекта в корень репозитория.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Выберите ветку `main` и папку `/(root)`, затем нажмите **Save**.
5. Дождитесь завершения публикации. Ссылка на сайт появится в разделе Pages.

## Что можно улучшить
Заменить учебные описания проектов на собственные результаты и добавить ссылки на реальные репозитории, когда они будут готовы. Не указывайте вымышленные контакты или навыки.
